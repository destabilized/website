macros

figuring out kmk (the firmware i'm using because i don't want to use qmk which is c-based) was quite hard, as the refrence i was using was extremely outdated, and their documentation is hard to find.

after finding it however, i took their quickstart and modified it slightly to reflect my pins

this is what it ended up looking like:

print("Starting")

import board

from kmk.kmk_keyboard import KMKKeyboard
from kmk.keys import KC
from kmk.scanners import DiodeOrientation

keyboard = KMKKeyboard()

keyboard.col_pins = (board.D3, board.D4, board.D5. board.D6)
keyboard.row_pins = (board.D7, board.D8)
keyboard.diode_orientation = DiodeOrientation.COL2ROW

keyboard.keymap = [
    [
        KC.Q, KC.W, KC.E, KC.R,
        KC.A, KC.S, KC.D, KC.F,
    ]
]

if __name__ == '__main__':
    keyboard.go()
pretty self-explanatory. it types one of the letters depending on which row / column pins are connected (i don't have the pcb yet). some of the letters may be different because i use colemak, not qwertyy
